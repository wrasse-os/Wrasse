# Agents

This file used to describe Bluefin and was wrong for this fork. The rules now live elsewhere:

- `CLAUDE.md`: working rules (no pushes, no local image builds, one concern per commit, commit prefixes, shell conventions).
- `docs/SPEC.md`: phases, decisions, pending decisions, repo facts and per-phase status notes.

- `docs/CI.md`: build matrix and release lines. `docs/UJUST.md`: ujust recipes. `docs/WRASSE-INSTALL.md`: the `wrasse` CLI.

Verify against the actual tree before relying on any description of Bluefin's layout.
